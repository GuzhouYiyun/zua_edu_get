# zua_edu_get

模拟登录郑州航空工业管理学院教务系统（jwglxt.zua.edu.cn），自动抓取学生课程表并导出为 Excel 文件（`课表.xlsx`，保存到桌面）。

## 功能特性

- 输入学年、学期，按学期查询课表
- 生成带合并单元格的 Excel 课表，保存至桌面 (~\Desktop\课表.xlsx)

## 环境要求

- Python 3.x
- 依赖库：`requests`、`openpyxl`

## 使用方法

1. 安装依赖：

   ```bash
   pip install requests openpyxl
   ```

   若下载缓慢，可使用清华镜像源：

   ```bash
   pip install requests openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

2. 运行脚本：

   ```bash
   python zua_edu_get.py
   ```
   或直接双击py运行

3. 按提示依次输入：
   - 学号
   - 密码
   - 开学学年年份后两位
   - 学期（`1` 上学期，`2` 下学期）

4. 运行完成后，桌面上会生成 `课表.xlsx`。

## 工作原理

1. 获取登录页，提取页面中的 SHA1 密钥，与密码拼接后计算哈希
2. 携带哈希密码 POST 登录教务系统，建立会话
3. 访问课表页面并查询学期 ID
4. 请求课表数据接口，通过正则解析课程、教室、教师、周次信息
5. 使用 openpyxl 生成带合并单元格的 Excel 课表

## 注意事项

- 未做登入失败的处理，请确保学号密码正确，报错或失败即错误。官网有限制，连错三次锁两分钟，可能会有验证码，自行官网登录刷新次数
- 仅供本人课程查询使用，会向教务系统提交学号和密码，请注意账号安全
- 教务系统接口或页面结构变动可能导致脚本失效
- 登录涉及个人账号信息，请勿将脚本或运行结果对外传播
