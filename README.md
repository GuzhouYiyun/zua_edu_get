# 课程表导出工具

自动登录郑州航空工业管理学院教务系统，抓取课程表并导出为 Excel 和 TXT 文件。

## 功能

- 自动登录教务系统，按学期查询课表
- 导出 Excel 课表（格式与教务系统一致）
- 导出 TXT 文本课表（按课程分类显示）

## 环境要求

- Python 3.x
- 依赖库：`requests`、`openpyxl`

## 使用步骤

### 1. 安装依赖

打开命令行，运行：

```bash
pip install requests openpyxl
```

若下载缓慢，使用清华镜像：

```bash
pip install requests openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 运行脚本

双击 `zua_edu_get.py` 运行，或在命令行中执行：

```bash
python zua_edu_get.py
```

### 3. 输入信息

按提示依次输入：

| 提示内容 | 输入说明 |
|---------|---------|
| 学号 | 你的学号 |
| 密码 | 你的教务系统密码 |
| 学期年份后两位 | 如 2026-2027 学年输入 `26` |
| 学期 | 上学期输入 `1`，下学期输入 `2` |

### 4. 查看结果

运行完成后，在桌面的 `课表` 文件夹中查看：

| 文件 | 说明 |
|------|------|
| `课表.xlsx` | Excel 课表，格式与教务系统一致 |
| `课表.txt` | 文本课表，按课程分类显示，便于快速查看与导入课表软件 |

## 注意事项

- 请确保学号和密码正确，由于官网限制，连续输错 3 次会锁定 2 分钟
- 教务系统接口变动可能导致脚本失效
- 仅供个人使用，请勿将脚本或结果对外传播
